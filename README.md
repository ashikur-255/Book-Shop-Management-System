## 📖 Overview
The **Book Shop Management System** is a robust and secure application built with C# to streamline daily bookstore operations. It is designed with a comprehensive Admin Dashboard, complete role-based user control, and full CRUD capabilities to efficiently manage inventory, customers, and sales records.

## ✨ Key Features
* 🔐 **Secure Authentication:** Complete login and registration system to ensure data privacy and secure access.
* 🛡️ **Role-Based Access Control:** Distinct user permissions and interfaces for **Admins** (full system control) and **Users/Staff** (restricted operational access).
* 📊 **Admin Dashboard:** A centralized control panel providing a quick overview of shop metrics, total books, active users, and system alerts.
* 🔄 **Full CRUD Operations:** Seamlessly Create, Read, Update, and Delete records for:
  * **Books:** Add new titles, update pricing, manage stock, and categorize genres.
  * **Users:** Manage staff and customer profiles, update roles, and track activity.
* 📦 **Inventory Management:** Real-time tracking of book availability to prevent stockouts and manage reordering.

## 🛠️ Technologies Used
* **Programming Language:** C#
* **Framework:** .NET / ASP.NET
* **Database:** Microsoft SQL Server
* **ORM:** Entity Framework (EF)
* **Architecture:** MVC / Three-Tier Architecture
